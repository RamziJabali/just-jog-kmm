# Just Jog Kotlin/Compose Multiplatform
## An Android and iOS jogging application done using KMM and CMP
- In an effort to get a strong understanding for the latest tech, I am creating a jogging application that utilizes a lot the core and basic functionality of mobile devices.
- Such as:
  -  Permission Handling
  -  Persistant Storage
  -  GPS Location
  -  Data usage

- I do plan on upgrading this into a bigger project once I have fulfilled the base goal of the project.
